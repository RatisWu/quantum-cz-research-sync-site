Quantum CZ Research Sync

A personal research utility operated by RatisWu for transferring operator-approved research summaries from an operator-managed Ubuntu device to an institution-managed Google Drive account using rclone and the Google Drive API.

Purpose and access

This utility is for the operator's authorized research workflow and has no public registration. Upload approval is an operator responsibility; OAuth does not review whether a document is suitable for transfer.

The intended Google OAuth scope is https://www.googleapis.com/auth/drive.file. It provides per-file access rather than access to all Drive content. In rclone, this normally limits visibility to files and folders created by rclone. Within that boundary, account permissions and the command used determine whether files can be read, updated, or deleted. This is not an upload-only permission.

The destination and available operations depend on institutional account permissions and administrator policies. An institution-managed account's My Drive and a Google Workspace shared drive are different destinations; access to an existing folder is not guaranteed by this scope.

Separate ChatGPT connection

If the operator later asks ChatGPT to read or work with uploaded documents, that access uses OpenAI's official Google Drive connection, authorized separately. It does not use this utility's rclone credentials. Its permissions are independent of this utility's drive.file scope and depend on the connected account and administrator settings.

Informational website

This static site describes the utility. It has no Google sign-in form, upload form, or application database and does not receive research documents or OAuth credentials. It is intended for a separate GitHub Pages project repository.
